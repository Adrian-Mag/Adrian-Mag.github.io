The Function-Space Bayesian Inverse Problem

The chosen ingredients

We now return from the detour. The pieces are on the table: model space, data space, forward map, noise model, prior measure, and the geometry needed to define the adjoint.

The central lesson is that these objects must be chosen before discretization. Only then does a matrix become a representation of something meaningful, rather than an accidental substitute for the problem itself.

The function-space Bayesian inverse problem begins with the data equation \(\obs = G m + \noise\). This equation now has a precise meaning because each symbol has a mathematical home: \(m\in\M\), \(\obs\in\D\), \(G:\M\to\D\), \(\noise\sim\N(0,\Cd)\), \(m\sim\prior\).

Lesson

The same equation that looked innocent in Act I now has a full mathematical skeleton. That skeleton is what prevents the discretization from inventing a different creature.

Model space

The unknown model lives in a chosen Hilbert space: \(\M = H^s(\Omega)\) or another chosen Hilbert space. The precise choice depends on the problem. The model space tells us which objects count as admissible models, what convergence means, what perturbations are small, what inner product defines the adjoint, and what kind of Gaussian prior can live on the space.

Warning

A basis does not choose the model space for us. A basis represents a space after the modelling decision has already been made.

Data space

The data space is finite-dimensional: \(\D = \R^K\). Since \(\D\) is finite-dimensional, several technical issues become easier. Nevertheless, the data space still has geometry. The statistically natural data misfit is \(\norm{\obs-G m}_{\Cd^{-1}}^2 = (\obs-G m)^{\top} \Cd^{-1}(\obs-G m)\).

Forward map

The forward map sends models to predicted data: \(G : \M \to \D\). The map \(G\) must be meaningful on the chosen model space. For example, if \(\M=L^2(\Omega)\) and \(K_i\in L^2(\Omega)\), then \(|[G m]_i| \leq \norm{K_i}_{L^2}\norm{m}_{L^2}\), so each component of \(G\) is a continuous linear functional on \(L^2(\Omega)\).

Noise model

The observational noise is Gaussian: \(\noise \sim \N(0,\Cd)\). Conditional on the model \(m\), the data are distributed as \(\obs\mid m \sim \N(G m,\Cd)\). The likelihood is \(\pi(\obs\mid m) \propto \exp\left( -\frac{1}{2} \norm{\obs-G m}_{\Cd^{-1}}^2 \right)\).

Prior measure

The prior is a probability measure on the model space: \(\prior = \N(m_0,C_0)\). For this to define a Gaussian measure on \(\M\), the covariance operator must be linear, symmetric, positive, and trace class: \(\Tr(C_0)<\infty\).

This is the step that repairs the naive prior. We no longer assign an independent variance \(\sigma^2\) to every coefficient introduced by the mesh. Instead, we choose a covariance operator that defines a genuine probability measure on functions.

Intuition

The prior covariance is the instrument panel of the random function. It controls amplitude, smoothness, correlation length, and boundary behaviour.

The posterior

Once the ingredients are chosen, the posterior is no longer a numerical guess. It is a probability measure on the same model space as the prior. Bayes' theorem in function space: \[ \frac{d\post}{d\prior}(m) = \frac{1}{Z(\obs)} \exp(-\Phi(m;\obs)), \] where \(Z(\obs) = \int_{\M} \exp(-\Phi(m;\obs)) \,d\prior(m)\).

Gaussian conditioning in function space

In the linear Gaussian case, the posterior is again Gaussian: \(\post = \N(m^{\obs},C^{\obs})\). The data covariance induced by the prior and noise is \(G C_0 G^{\adj} + \Cd\), a finite-dimensional covariance on the data space.

Posterior covariance

\[ C^{\obs} = C_0 - C_0 G^{\adj} \left( G C_0 G^{\adj} + \Cd \right)^{-1} G C_0. \] Each symbol now refers to an operator between chosen spaces. The update term is the amount of prior covariance removed by the data. Since the data space is finite-dimensional, the update can only affect finitely many data-informed directions.

Because the prior covariance is trace class, the posterior covariance remains controlled: \(0 \leq C^{\obs} \leq C_0\), and therefore \(\Tr(C^{\obs})\leq \Tr(C_0)<\infty\). This is the mathematical antidote to the divergence seen in the naive posterior.

Posterior mean

\[ m^{\obs} = m_0 + C_0 G^{\adj} \left( G C_0 G^{\adj} + \Cd \right)^{-1} (\obs - G m_0). \] The residual \(\obs-G m_0\) lives in the data space. The inverse weights it by the combined uncertainty from the prior and the noise. The adjoint \(G^{\adj}\) then pulls this data-space information back into the model space. Finally, \(C_0\) shapes the update according to the prior covariance.

Lesson

The posterior mean is the prior mean plus a data-driven correction. The adjoint decides how data residuals enter model space, and the covariance decides which model directions are allowed to respond.

Discretization after formulation

We now discretize, but the order has changed. We are no longer using discretization to define the inverse problem. We are using discretization to approximate an inverse problem that already exists.

Choose finite-dimensional approximation spaces \(\M_N \subset \M\). A discrete model is \(m_N(x) = \sum_{j=1}^N [\mathbf{u}]_j\phi_j(x)\). The key difference from the naive approach is conceptual: \(\M_N\) approximates \(\M\). It does not replace \(\M\) as the starting point of the problem.

The guiding principle is: discrete object = representation of continuous object. The prior covariance should be obtained from the continuous covariance operator, not invented independently at each resolution.

Respecting inner products

The model-space Gram matrix is \([\Mb]_{ij} = \inner{\phi_i}{\phi_j}_{\M}\). The mass or Gram matrix is the coordinate expression of the model-space geometry. The discrete adjoint must respect both geometries: \(G^{\adj}_{\mathrm{disc}} = \Mb^{-1}\Gb^{\T} \Wb_D\).

Warning

Replacing \(G^{\adj}_{\mathrm{disc}}\) by \(\Gb^{\T}\) is valid only in the special case where the chosen coordinates are orthonormal for the chosen inner products.

Respecting covariance operators

The discrete covariance must approximate the continuous covariance operator \(C_0\). If \(C_0\) is defined through a differential operator, such as \(C_0 = \alpha(\kappa^2 I-\Delta)^{-s}\), then the discrete covariance should come from a discretization of that operator and its inverse power. The important point is that \(\mathbf{C}_{0,N}\) is not chosen merely because it is a positive matrix. It is chosen because it approximates \(C_0\).

Respecting boundary conditions

If the prior covariance is built from a differential operator, then boundary conditions are part of the prior. The discretization must respect the same boundary conditions.

Lesson

Boundary conditions do not enter at the edge of the code. They enter at the definition of the covariance operator.

Why the initial problems melt away

The prior has a continuous meaning

In the function-space construction, we choose \(m\sim\N(m_0,C_0)\) first. The discrete priors are then approximations of this same prior. Increasing \(N\) no longer introduces a new Bayesian model with more independent variance. Instead, it improves the approximation of the same continuous prior.

The covariance has bounded trace

In the corrected formulation, we require \(\Tr(C_0)<\infty\), so \(\E\norm{m-m_0}_{\M}^2 = \Tr(C_0) < \infty\). The posterior covariance satisfies \(0\leq C^{\obs}\leq C_0\), and therefore \(\Tr(C^{\obs})\leq \Tr(C_0)<\infty\). The posterior uncertainty is controlled by construction.

Proposition

Let \(\M\) be a Hilbert space, let \(C_0\) be a positive symmetric trace-class covariance operator on \(\M\), and let \(G:\M\to\D\) be a bounded linear map into the finite-dimensional data space \(\D=\R^K\). Suppose \(\Cd\) is symmetric positive definite. Then the posterior covariance \(C^{\obs} = C_0 - C_0 G^{\adj} (G C_0 G^{\adj} + \Cd)^{-1} G C_0\) is positive and trace class, with \(\Tr(C^{\obs})\leq\Tr(C_0)\).

The posterior covariance is obtained by conditioning a joint Gaussian measure. Conditioning reduces uncertainty in the positive-operator sense, so \(0\leq C^{\obs}\leq C_0\). Since \(C_0\) is trace class and \(C^{\obs}\) is positive and dominated by \(C_0\), it is also trace class and satisfies \(\Tr(C^{\obs})\leq \Tr(C_0)\).

The adjoint is geometry-aware

In the function-space formulation, the adjoint is defined by \(\inner{G m}{d}_{\D} = \inner{m}{G^{\adj} d}_{\M}\). After discretization, this becomes \(G^{\adj}_{\mathrm{disc}} = \Mb^{-1}\Gb^{\T} \Wb_D\). The discrete posterior formulas are built from the adjoint determined by the spaces, not from a raw transpose. The model-space geometry now travels with the computation.

Samples remain controlled under refinement

Unlike the naive prior, refinement does not add independent variance of fixed size to every new direction. New directions receive the amount of variance prescribed by the continuous covariance operator. For a trace-class covariance, the total remaining variance in high modes becomes small.

Intuition

Refinement no longer opens new trapdoors of variance. It reveals finer pieces of the same probability measure.

The posterior converges

The continuous posterior \(\post=\N(m^{\obs},C^{\obs})\) is the target. The discrete posteriors \(\post_N\) should approximate it. In a well-designed discretization, one expects convergence in an appropriate sense: \(\post_N \to \post\) as \(N\to\infty\).

This was missing in the naive workflow. There, the sequence \(\post_1,\post_2,\post_3,\ldots\) was not clearly approximating anything. In the corrected workflow, the continuous posterior is defined first, and the discrete posteriors are judged by how well they approximate it.

Lesson

The cure is not a cleverer matrix. The cure is choosing the mathematical object first and discretizing it second.

The corrected workflow

The naive workflow was:

mesh \(\Rightarrow\) basis \(\Rightarrow\) coefficient vector \(\Rightarrow\) matrix prior \(\Rightarrow\) posterior.

The corrected workflow is:

model space \(\Rightarrow\) data space \(\Rightarrow\) forward map \(\Rightarrow\) noise model \(\Rightarrow\) prior measure \(\Rightarrow\) posterior \(\Rightarrow\) discretization.

More explicitly:

  1. Choose the model space \(\M\).
  2. Choose the data space \(\D\).
  3. Define the forward map \(G:\M\to\D\).
  4. Specify the noise model \(\noise\sim\N(0,\Cd)\).
  5. Choose the prior measure \(\prior=\N(m_0,C_0)\) on \(\M\).
  6. Define the posterior measure \(\post\) on \(\M\).
  7. Choose approximation spaces \(\M_N\subset\M\).
  8. Discretize \(G\), \(G^{\adj}\), \(C_0\), and the posterior consistently.

This order protects the problem from accidental modelling choices.

The moral of Act VII

The opening example looked harmless because every finite-dimensional step was legal. But legal finite-dimensional algebra does not guarantee a coherent infinite-dimensional inverse problem.

The corrected formulation changes the foundation. We first choose \(\M, \D, G, \Cd, \prior\). Then we define \(\post = \N(m^{\obs},C^{\obs})\). Only then do we discretize.

The posterior mean, covariance, samples, and refinement behaviour now belong to one mathematical story. The plot no longer has to hide a monster under the mean.

Checkpoint

The final return to the toy problem is now straightforward. We will solve the same opening example again, but this time the prior will be a genuine function-space Gaussian, the adjoint will respect the chosen geometry, and mesh refinement will approximate the posterior rather than rewriting the problem.
