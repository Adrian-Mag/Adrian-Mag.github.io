Inside an Agentic Workspace

A real, curated file tree showing how AI-related instructions, checks, notes, scripts, and outputs are spread across this website workspace.

Last reviewed: 24 July 2026, against the live workspace structure. This is a curated structural view, so it deliberately leaves out folders unrelated to agent-assisted work. Select a folder to open it recursively, just as in a code editor, or select any file or shortcut to learn its role.

docs/agent-docs/ is the workspace’s durable record store: the cross-protocol map, commit convention, plans, references, Citation Audit, Agent Ledger, and ignored legacy continuity bridge live there. Skills are different. They are selected abilities, visible through agent discovery folders and physically stored with their recipes and helper programs; some abilities read or update a durable record, but they are not that record.

No file contents are loaded or copied into this page. Local-only entries are named because their position matters, but the explanation on the right replaces their contents.
