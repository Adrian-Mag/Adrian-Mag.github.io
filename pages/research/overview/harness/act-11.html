Act 11 Current as of July 2026

When one loop is not enough: graphs, subagent delegation, who supplies the harness versus who supplies the deployment. With the counterweight: most tasks do not need this.

Orchestration begins when one loop is no longer enough. Instead of one agent choosing the next action, a harness can route work through several steps, branches, or agents. A graph is a useful picture: nodes do work or hold state; edges say what can happen next.

That picture can become theatrical very quickly. A graph is not proof that a system needs many agents, and a second model call does not repair a vague task. In the small website workflow used throughout these acts, the useful graph is mostly ordinary engineering: instructions route to a plan, the plan routes to source and page files, checks feed evidence back into a handoff, and the next task starts from verified state.

When a graph earns its cost

Split work only when the split gives something concrete: independent evidence, a different permission boundary, a separate tool contract, or a review point with a named owner. The public hook and tool demonstrations in this workspace are good examples of boundary nodes. They do not make a multi-agent system; they make particular operations inspectable and repeatable.

Multiple agents add queues, duplicated context, conflicting summaries, and a new question: who checks the checker? For most changes, a single well-informed loop with retrieval, tests, and a handoff is cheaper and easier to audit. Anthropic’s current workflow guidance makes the same caution: improve a single call and its context before adding orchestration. 1

Control is not deployment

The map is a description of this workspace’s agent-facing structure, not a deployed service architecture. The browser serves static files. The agent-docs library holds plans, references, citation evidence, and the soft Agent Ledger. The local control overlay helps an agent resume work through a legacy continuity bridge. The figure-generation scripts create assets on demand. None of those facts imply background workers, autonomous changes, or a hidden team of agents.

That is the final discipline of the series: name the loop, name the boundary, and name the evidence. If a box cannot be pointed to in source or observed in a check, it belongs in a proposal, not in a capability claim.
