The Machine Around the Model

An interactive map of the agentic structure in this website workspace.

A practical wiring diagram

One model chip; a whole board around it

Imagine a capable house-building robot. Its model is the chip that helps choose the next move; the host gives it eyes, hands, tools, and locked doors; the workspace supplies durable house manuals and records. Skills are separate job kits: they may read or update a manual, but the kit is not itself the house’s long-term memory. This diagram puts that distinction on the table without pretending that a folder is automatic memory.

How to read it. Drag to pan; use the wheel or controls to zoom. Click a component for a plain-language explanation. Solid blue paths are supplied by the host; orange paths are this workspace’s soft control routine; green paths are evidence checks; yellow paths are abilities an agent may choose. The two yellow links show skills attached to durable records. The dashed grey route is an honest gap: there is no always-running monitoring service here.

Last reviewed: 24 July 2026, against this workspace’s live agent-document protocols, provider adapters, local legacy bridge, and generated teaching assets.

The outer and inner loops are different

The blue outer path is ordinary host or session behaviour: an answer can lead to prompt N+1. It does not make the agent reopen BOOTSTRAP.md. The orange routine begins for a new task, a resumed session, or a changed workspace identity. While that routine is active, a material change in scope, evidence, or phase returns to the smaller plan decision, not to bootstrap.

The SSD is the agent-documents library

docs/agent-docs/ holds the cross-protocol map, commit convention, plans, references, Citation Audit, the Agent Ledger, and the ignored legacy bridge. These durable records enter context only when the host supplies them or a task selects them. The bridge remains live, but it is not the intended long-term architecture.

Skills are attached abilities

A skill is a selected kit: its short description can be visible to an agent, while its recipe and helpers load only when relevant. A kit may read or update a durable record without becoming that record. Here website-control uses the private continuity bridge, while pdf-source-reading is required before Citation Audit opens a local PDF.

Observation is not control

The Agent Ledger records declared steps and a few supported host observations. It does not choose a route, grant permission, or prove understanding. Focused checks still follow the work: a notes-page prose edit refreshes search data, an interaction needs a browser check, and a figure job has its own pipeline checks.
