Part 2: The Observation Kernel

The noise model as an epistemological object.

Part of Bayesian and Frequentist Inference.

« Overview 1 The Setup 2 The Observation Kernel 3 Bayesian Path 4 Frequentist Path 5 Beyond Additive

From realized noise to a noise model

In the ontological observation equation \(\dobs = \dtrue + \nobs\), the quantity \(\nobs\) denotes the actual noise that occurred. To reason about uncertainty, we introduce a mathematical model for possible noise realizations: a random variable \[ \Nrand : \Omega \to \Dspace \] with probability law \(\Nrand \sim \muN\).

The measure \(\muN\) describes which noise values are considered plausible, likely, unlikely, or extreme according to the assumed observation model. For example, if the noise is centred and Gaussian, noise values near zero receive high density, while large deviations receive low density.

Two kinds of objects

Ontological noise: \(\nobs\) is the actual error that occurred.

Epistemological noise model: \(\Nrand \sim \muN\) is the mathematical model for possible errors.

The noise law \(\muN\) tells us how the observation procedure behaves probabilistically. It does not, by itself, identify the particular noise realization in the actual experiment.

The shifted noise measure

If \(\dtrue\) were known, we could combine it with the noise random variable and construct a random observed datum \(\Dobsrand = \dtrue + \Nrand\). Define the translation map \[ T_{\dtrue} : \Dspace \to \Dspace, \qquad T_{\dtrue}(\mathbf n) = \dtrue + \mathbf n. \] The law of \(\Dobsrand\) is the pushforward of \(\muN\) through \(T_{\dtrue}\): \[ \mu_{\dtrue} = (T_{\dtrue})_{\#}\muN, \] meaning that for every measurable set \(A \subseteq \Dspace\), \[ \mu_{\dtrue}(A) = \muN(A - \dtrue). \] If \(\muN\) has a density \(p_N\), the shifted observation law has density \[ p_{\dtrue}(\mathbf d') = p_N(\mathbf d' - \dtrue). \]

This expression already reveals the central difficulty. To evaluate how plausible the observation is under the true shifted noise law, one needs the residual \(\dobs - \dtrue\). But \(\dtrue\) is unknown. When a density exists, plausibility is measured by the density at \(\dobs\); when no density exists, one works directly with the noise measure of neighbourhoods around the implied residual.

Candidate true data and the observation kernel

Since \(\dtrue\) is unknown, we cannot construct the shifted noise law centred at \(\dtrue\). What we can do is consider possible candidate values. For each candidate \(\mathbf d \in \Dspace\), the observation model would be \(\Dobsrand_{\mathbf d} = \mathbf d + \Nrand\), with law \[ \mu_{\mathbf d} = (T_{\mathbf d})_{\#}\muN, \qquad \mu_{\mathbf d}(A) = \muN(A - \mathbf d). \] If a density exists, the density at the actual observed datum is \[ p(\dobs \mid \mathbf d) = p_N(\dobs - \mathbf d). \] This measures how plausible the observed datum would be if \(\mathbf d\) were the true datum. In continuous data spaces, the literal probability of observing exactly \(\dobs\) is zero; the density (or the probability of a small neighbourhood around \(\dobs\)) is the appropriate measure of plausibility.

The assignment \[ \mathbf d \longmapsto \mu_{\mathbf d} \] is the observation kernel. More explicitly: \[ \L : \Dspace \times \Sigma_{\Dspace} \to [0,1], \qquad \L(\mathbf d, A) = \mu_{\mathbf d}(A) = \muN(A - \mathbf d). \] For each fixed candidate truth \(\mathbf d\), the map \(A \mapsto \L(\mathbf d, A)\) is a probability measure on the observation space. For each fixed observation event \(A\), the map \(\mathbf d \mapsto \L(\mathbf d, A)\) describes how the probability of observing \(A\) depends on the candidate truth.

Direction matters

The observation kernel has the direction: \[ \text{candidate truth} \longmapsto \text{probability measure on possible observations}. \] It does not map observations to probability measures on truths. That reverse direction requires a prior.

What the observation kernel can say

The observation kernel can answer candidate-wise questions. For a proposed true datum \(\mathbf d\), it asks: if \(\mathbf d\) were true, would \(\dobs\) be a plausible outcome of the noise model?

(Read as a function of the candidate \(\mathbf d\) with the observation held fixed, the kernel is precisely the object Fisher named the likelihood [Fis22]; the measure-theoretic scaffolding that lets us treat all of these objects as honest probability measures is Kolmogorov’s [Kol33].)

In the additive setting, this reduces to examining the implied noise \(\dobs - \mathbf d\). If this lies in a high-probability region of \(\muN\), the candidate is compatible; if it lies in a low-probability region, the candidate is less compatible.

For example, if \(E_\alpha \subseteq \Dspace\) is a noise region with \(\muN(E_\alpha) = 1 - \alpha\), then a candidate \(\mathbf d\) is compatible at level \(1-\alpha\) if \(\dobs - \mathbf d \in E_\alpha\), or equivalently \(\mathbf d \in \dobs - E_\alpha\). This is the basic frequentist compatibility idea that will later become a confidence set.

What the observation kernel cannot say alone

The observation kernel does not, by itself, assign probabilities to candidate true data values. It tells us how plausible the observation would be if \(\mathbf d\) were true — via density or neighbourhood probability, not literal point probability in continuous settings — but not how probable \(\mathbf d\) is given the observation.

A posterior distribution would have the opposite direction: \(\dobs \longmapsto\) probability measure on possible true data values. To construct such a posterior, one needs a prior measure on possible true data values. Without that prior, the likelihood values \(\ell_{\dobs}(\mathbf d) = p_N(\dobs - \mathbf d)\) are compatibility scores, not probabilities over \(\mathbf d\).

Not licensed by likelihood alone

The statement \(\Prob(\dtrue \in A \mid \dobs) = 0.95\) requires a probability model for \(\dtrue\). The observation kernel provides only the family of observation laws \(\{\mu_{\mathbf d} : \mathbf d \in \Dspace\}\). It does not provide a probability law on \(\mathbf d\).

The observation kernel is therefore a crucial object shared by both Bayesian and frequentist reasoning, but it is not yet a full inference about the truth. What one does with that family of laws is where the Bayesian and frequentist constructions begin to diverge.
