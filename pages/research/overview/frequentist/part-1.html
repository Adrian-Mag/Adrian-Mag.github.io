Part 1: The Setup

The ontological observation equation.

Part of Bayesian and Frequentist Inference.

1 The Setup 2 The Likelihood 3 Bayesian Path 4 Frequentist Path 5 Beyond Additive

The guiding question

We begin with a simple observation equation: \[ \dobs=\dtrue+\nobs. \] Here \(\dobs\) is the datum that has actually been observed, \(\dtrue\) is the unknown true datum, and \(\nobs\) is the actual realized observational error. This equation is not yet Bayesian or frequentist. It is simply a statement about the relation between the true datum, the observed datum, and the error that occurred.

The guiding question is: \[ \text{What can be said about } \dtrue \text{ after observing } \dobs\,? \] Since \(\dobs=\dtrue+\nobs\), one might hope that knowing \(\dobs\) and having a probabilistic model for the noise would immediately yield a probabilistic statement about \(\dtrue\). But this is not automatic.

If \(\dtrue\) were known, we could imagine repeating the observation many times: each time, the same true datum would be combined with a different noise realization, producing different observed data. The probability law of those observed data would be the noise law shifted by \(\dtrue\), and we could ask whether \(\dobs\) looks typical or atypical under that law. But in the inverse problem, \(\dtrue\) is precisely what is unknown. There is not one single observation law — there is a family of possible observation laws, one for each candidate true datum. Each candidate truth, combined with the noise model, generates its own prediction about what observations should look like.

This family is called the likelihood kernel. It tells us how plausible the observed datum would be under each candidate truth, but by itself it does not assign probabilities to the candidate truths.

The Bayesian and frequentist approaches part ways at this point:

Bayesian question. Given \(\dobs\), how should probability be distributed over possible true data values?

Frequentist question. Can we construct a procedure which reliably captures or tests the fixed truth under repeated observations?

Both questions are meaningful, but they are not the same question.

The actual objects

The quantities involved in the real measurement are not random variables — they are realized quantities:

  • True datum \(\dtrue \in \Dspace\): the datum that would be obtained if the observation process were perfect.
  • Observed datum \(\dobs \in \Dspace\): the datum that was actually recorded.
  • Realized noise \(\nobs \in \Dspace\): the particular error that occurred in the observation process.

These three quantities are not random merely because we do not know them. Once the observation has happened, reality has already selected the values \(\dtrue\), \(\dobs\), and \(\nobs\). Some may be hidden from us, but their hiddenness is an epistemological issue, not an ontological one.

Key distinction

Random variables — mathematical objects introduced to represent uncertainty, variability, or repeated sampling — are epistemological constructions. They are not the same kind of object as the actual realized quantities \(\nobs\), \(\dtrue\), and \(\dobs\). We will introduce such random variables in the next part, when we build the noise model and the likelihood kernel.

What is known and what is hidden

After the observation, the known quantity is \(\dobs\). The hidden quantities are \(\dtrue\) and \(\nobs\). The true datum is hidden because the measurement is noisy. The realized noise is hidden because it can only be computed if \(\dtrue\) is already known.

This creates a circular-looking difficulty: \[ \nobs=\dobs-\dtrue. \] To know the noise, we would need to know the truth. But to know the truth, we would need to know the noise.

From the observed datum alone, the decomposition \(\dobs = \dtrue + \nobs\) is not identifiable. For any candidate true datum \(\mathbf d \in \Dspace\), one can define an implied realized noise \[ \mathbf n_{\mathrm{implied}} = \dobs - \mathbf d. \] The observation can always be explained by many different candidate truths, each paired with a different implied noise.

The role of a noise model is to distinguish among these explanations by saying which implied noises are plausible and which are not. But that step already introduces an epistemological object — it is no longer just the realized observation equation.

Why the distinction matters

Many interpretational mistakes come from silently replacing ontological objects by epistemological random variables, or from using frequentist confidence statements as though they were Bayesian posterior probability statements.

Here is a concrete example of the kind of confusion that arises. A frequentist confidence set is a rule that takes an observation and returns a set of candidate truths. Before the observation is made, the observation is random, so the confidence set is also random. The frequentist can calibrate the procedure so that, over many hypothetical repetitions of the experiment, the random confidence set contains the fixed true datum with a specified frequency — say \(95\%\).

After the observation is made, the rule produces a concrete, fixed set. At this point, either the true datum lies inside that set or it does not — there is no more randomness in the frequentist model. It is tempting to say “the probability that the true datum lies in this set is \(95\%\),” but that statement requires a probability model for the true datum after observing — which is a Bayesian-type object, not something the frequentist construction provides.

Common confusion

The statement “the procedure catches the truth with frequency \(95\%\)” is not the same as “the probability that the truth lies in this particular realized set is \(95\%\).” The first is a pre-observation statement about a random procedure. The second is a post-observation statement that requires a probability law for the true datum.

The organizing principle

Once the ontological and epistemological layers are separated, the Bayesian and frequentist constructions become easier to compare:

Bayesian inference places probability on an epistemological representation of the truth.

Frequentist inference places probability on the observation procedure while keeping the truth fixed.

This separation will be the organizing principle for everything that follows. The next part introduces the first major epistemological construction built from the noise model: the likelihood kernel.
