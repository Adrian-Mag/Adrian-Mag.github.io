Part 4: The Frequentist Path

Truth fixed, observation random, calibrated procedures.

Part of Bayesian and Frequentist Inference.

Refusing the epistemological true-datum random variable

The frequentist construction begins from the same ontological observation equation \(\dobs = \dtrue + \nobs\), but refuses one of the Bayesian moves. In the Neyman confidence-set framework considered here, the frequentist does not introduce an epistemological true-datum random variable \(\Drand \sim \prior\). The true datum is not assigned a probability law. It is treated as fixed but unknown.

Instead, probability is placed on the observation procedure through the noise random variable \(\Nrand \sim \muN\). The frequentist does not try to construct a posterior probability measure \(\Prob(\dtrue \in A \mid \dobs)\). Instead, the frequentist asks:

Can we construct a procedure which behaves reliably under repeated noisy observations, no matter what the fixed true datum actually is?

The frequentist does not produce a probability distribution over possible truths. The frequentist produces a calibrated procedure. The truth is fixed. The data-generating process is random. The procedure is judged by how it behaves across repeated draws from that process.

Truth fixed, observation random

In the frequentist model, \(\dtrue\) is fixed and \(\Nrand \sim \muN\), so before the observation the polluted datum is \(\Dobsrand = \dtrue + \Nrand\). This looks similar to the Bayesian \(\Dobsrand = \Drand + \Nrand\), but the interpretation is different: in the Bayesian model \(\Drand\) is random; in the frequentist model \(\dtrue\) is fixed.

If the experiment were repeated many times under the same \(\dtrue\), we would obtain different observations \(\Dobsrand_1, \Dobsrand_2, \dots\) because the noise realizes differently each time: \(\Dobsrand_j = \dtrue + \Nrand_j\). The true datum stays fixed throughout. It is the observations that move around it.

Candidate-wise compatibility

Since \(\dtrue\) is unknown, the frequentist considers candidate true data values \(\mathbf d \in \Dspace\). For each candidate, the implied noise is \(\mathbf n_{\mathrm{implied}}(\mathbf d) = \dobs - \mathbf d\). The candidate is compatible if this implied noise looks plausible under \(\muN\).

The frequentist does not ask “how probable is \(\mathbf d\) given \(\dobs\)?” but rather “if \(\mathbf d\) were the truth, would \(\dobs\) require a plausible noise realization?” This is the same candidate-wise logic present in the observation kernel, used to construct tests and confidence sets rather than a posterior measure.

Noise acceptance regions

Choose a measurable noise acceptance region \(E_\alpha \subseteq \Dspace\) with \(\muN(E_\alpha) \ge 1 - \alpha\). This set contains noise realizations regarded as ordinary at level \(1-\alpha\); its complement contains those regarded as extreme. When the noise distribution is continuous, one can typically choose \(E_\alpha\) so that \(\muN(E_\alpha) = 1-\alpha\) exactly; in discrete settings or under restricted shapes, exact equality may be unattainable and the region is conservative.

For example, if \(\Nrand \sim \mathcal{N}(0, \sigma^2)\), a symmetric \(95\%\) acceptance region is \(E_{0.05} = [-1.96\sigma, 1.96\sigma]\). In higher dimensions, \(E_\alpha\) may be an ellipsoid, a box, a ball, or another set chosen to have noise probability \(1-\alpha\).

Confidence sets from shifted noise regions

Given the observed datum \(\dobs\), define the confidence set \[ \Calpha(\dobs) = \left\{ \mathbf d \in \Dspace : \dobs - \mathbf d \in E_\alpha \right\}. \] This contains all candidate true data values whose implied noise lies in the accepted region. Equivalently, \(\Calpha(\dobs) = \dobs - E_\alpha\).

The logic is: \[ \begin{aligned} \text{accepted noise values} &\quad \mathbf n \in E_\alpha, \\ \text{observation equation} &\quad \dobs = \mathbf d + \mathbf n, \\ \text{candidate truth} &\quad \mathbf d = \dobs - \mathbf n. \end{aligned} \] The confidence set is not produced by assigning probabilities to candidate truths. It is produced by translating accepted noise realizations into compatible true data values.

The pre-observation random confidence set

Before the observation, \(\Dobsrand = \dtrue + \Nrand\) is random, so the confidence set is also random: \[ \Calpha(\Dobsrand) = \left\{ \mathbf d : \Dobsrand - \mathbf d \in E_\alpha \right\}. \] If the experiment is repeated many times with the same fixed \(\dtrue\), we obtain a sequence of random confidence sets \(\Calpha(\Dobsrand_1), \Calpha(\Dobsrand_2), \dots\). Some contain \(\dtrue\); some may not. The frequentist calibration concerns the long-run frequency with which they do.

The coverage statement

By definition, \(\dtrue \in \Calpha(\Dobsrand)\) if and only if \(\Dobsrand - \dtrue \in E_\alpha\). But in the frequentist model, \(\Dobsrand - \dtrue = \Nrand\). Therefore: \[ \dtrue \in \Calpha(\Dobsrand) \quad\Longleftrightarrow\quad \Nrand \in E_\alpha. \] Taking probabilities: \[ \begin{aligned} \Prob_{\dtrue}\!\left( \dtrue \in \Calpha(\Dobsrand) \right) &= \Prob_{\dtrue}\!\left( \Dobsrand - \dtrue \in E_\alpha \right) \\ &= \Prob\!\left(\Nrand \in E_\alpha\right) \\ &= \muN(E_\alpha) \ge 1 - \alpha. \end{aligned} \]

Frequentist coverage

\[ \Prob_{\dtrue}\!\left( \dtrue \in \Calpha(\Dobsrand) \right) \ge 1 - \alpha. \]

The subscript \(\dtrue\) indicates the probability is computed under the sampling law in which \(\dtrue\) is the fixed true datum. The probability is over \(\Dobsrand\) (equivalently \(\Nrand\)), not over \(\dtrue\).

In words: if the true datum is fixed at \(\dtrue\), and the noisy observation procedure is repeated many times, then the confidence set contains \(\dtrue\) in at least a fraction \(1-\alpha\) of repetitions. When exact acceptance regions are available (as in continuous models), the coverage is exactly \(1-\alpha\); in discrete or restricted settings, the coverage may be conservative.

The realized confidence set

After the observation, the random \(\Dobsrand\) is replaced by the actual \(\dobs\). The confidence set becomes \(\Calpha(\dobs)\) — a fixed set. At this point, \(\dtrue \in \Calpha(\dobs)\) is either true or false. The frequentist generally does not know which, because \(\dtrue\) is hidden.

The subtle distinction

Before observation: \(\Calpha(\Dobsrand)\) is random, so it makes sense to ask for the probability that it contains \(\dtrue\).

After observation: \(\Calpha(\dobs)\) is fixed, so the statement that it contains \(\dtrue\) is no longer a random event unless one introduces a probability law for \(\dtrue\).

What the frequentist does and does not claim

The frequentist does claim: \[ \Prob_{\dtrue}\!\left( \dtrue \in \Calpha(\Dobsrand) \right) \ge 1 - \alpha. \] This is a statement about a random confidence set before the observation is realized. Equivalently: the rule \(\dobs \mapsto \Calpha(\dobs)\) catches the fixed truth with frequency at least \(1-\alpha\) under repeated noisy observations.

The frequentist does not automatically claim: \[ \Prob\!\left( \dtrue \in \Calpha(\dobs) \right) = 1 - \alpha. \] This would be a statement about the probability that the fixed truth lies in the already-realized set. To make such a statement, one would need a probability model for \(\dtrue\), which the frequentist construction has deliberately not introduced.

Two statements, kept separate

Frequentist coverage: A random confidence set catches a fixed truth with probability at least \(1-\alpha\).

Posterior-style statement: A fixed realized set contains an uncertain truth with probability \(1-\alpha\).

The first is licensed by the sampling model. The second requires a probability distribution over possible true data values.

The distinctive frequentist rhythm

The realized confidence set \(\Calpha(\dobs)\) is not useless — it has a concrete compatibility interpretation. It tells us which candidate truths survive the noise-based compatibility test. The calibration is pre-observation; the output is post-observation.

Before seeing data: Design a rule with known repeated-sampling behaviour.

After seeing data: Apply the rule to obtain a concrete set of compatible truths.

Interpretation: Trust the output through the calibration of the rule, not through a posterior probability assigned to the realized set.
