Part 5: Beyond Additive Noise

General sampling laws, test statistics, and decision rules.

Part of Bayesian and Frequentist Inference.

The general starting point

So far we assumed an additive observation model \(\Dobsrand = \dtrue + \Nrand\) with a single noise law \(\muN\). In that special case, all candidate true data share the same noise distribution, and the observation law under candidate \(\mathbf d\) is obtained by translation: \(\mu_{\mathbf d}(A) = \muN(A - \mathbf d)\).

This shifted-noise picture is useful, but not the most general frequentist construction. In many problems, the observational uncertainty may depend on the true datum, or the observation may not be generated by simple addition at all. The noise may be multiplicative, signal-dependent, nonlinear, or produced by an observation mechanism that cannot be written cleanly as truth + noise.

The more general starting point is the observation kernel itself. For each candidate \(\mathbf d \in \Dspace\), we assume there is a probability measure \(\L(\mathbf d, \cdot)\) on the observation space. The general sampling model is \[ \mathbf d \longmapsto \L(\mathbf d, \cdot). \] This may come from an additive model, a heteroscedastic additive model, a multiplicative model, a nonlinear simulator, or any other stochastic observation mechanism. The frequentist construction does not require the observation law to be a shifted copy of a single noise measure.

Candidate-dependent observation laws

In the additive homoscedastic case: \(\L(\mathbf d, A) = \muN(A - \mathbf d)\).

In a heteroscedastic additive case, the noise law may depend on the candidate: \[ \Dobsrand_{\mathbf d} = \mathbf d + \Nrand_{\mathbf d}, \qquad \Nrand_{\mathbf d} \sim \mu_{N \mid \mathbf d}, \] giving \(\L(\mathbf d, A) = \mu_{N \mid \mathbf d}(A - \mathbf d)\).

More generally, one may have an observation mechanism \(\Dobsrand_{\mathbf d} = H(\mathbf d, \mathbf W)\), where \(\mathbf W\) is a random variable representing all unresolved randomness. Then \(\L(\mathbf d, A) = \Prob(H(\mathbf d, \mathbf W) \in A)\). The notation \(\L(\mathbf d, \cdot)\) does not require us to decide whether the noise is additive, multiplicative, heteroscedastic, nonlinear, or something else.

Candidate-dependent acceptance regions

To construct confidence sets in this general setting, we no longer begin with one fixed noise region \(E_\alpha\). Instead, for each candidate \(\mathbf d\), we choose an acceptance region in observation space: \[ A_{\alpha}(\mathbf d) \subseteq \Dspace, \] satisfying \(\L(\mathbf d, A_{\alpha}(\mathbf d)) = 1 - \alpha\) (or \(\geq 1 - \alpha\) for conservative regions).

The candidate \(\mathbf d\) is compatible with the observation \(\dobs\) when \(\dobs \in A_{\alpha}(\mathbf d)\). In the additive homoscedastic case, this reduces to \(A_{\alpha}(\mathbf d) = \mathbf d + E_\alpha\), and the condition becomes \(\dobs - \mathbf d \in E_\alpha\) as before. But in the general case, the fundamental condition is simply \(\dobs \in A_{\alpha}(\mathbf d)\).

Confidence sets under general sampling laws

The general confidence set is \[ \Calpha(\dobs) = \left\{ \mathbf d \in \Dspace : \dobs \in A_{\alpha}(\mathbf d) \right\}. \] This contains exactly those candidate true data values for which the actual observation would not be rejected as unusual. In a multiplicative or nonlinear model, there may be no meaningful residual of the form \(\dobs - \mathbf d\), but the confidence set is still well-defined.

Test inversion

The shifted-noise construction is a special case. The deeper frequentist construction is test inversion: test each candidate truth, then keep the candidates not rejected.

Using test statistics

Acceptance regions are often constructed using a test statistic \(T : \Dspace \times \Dspace \to \mathbb{R}\), where \(T(\mathbf d, \mathbf d')\) measures how unusual the observation \(\mathbf d'\) would be if \(\mathbf d\) were true. For each candidate \(\mathbf d\), choose a critical value \(c_{\alpha}(\mathbf d)\) such that \[ \L\!\left( \mathbf d, \{\mathbf d' : T(\mathbf d, \mathbf d') \leq c_{\alpha}(\mathbf d)\} \right) = 1 - \alpha. \] Then \(A_{\alpha}(\mathbf d) = \{\mathbf d' : T(\mathbf d, \mathbf d') \leq c_{\alpha}(\mathbf d)\}\) and the confidence set becomes \[ \Calpha(\dobs) = \left\{ \mathbf d : T(\mathbf d, \dobs) \leq c_{\alpha}(\mathbf d) \right\}. \]

In the scalar Gaussian additive case \(D'_{\theta} = \theta + N\), \(N \sim \mathcal{N}(0, \sigma^2)\), one possible statistic is \(T(\theta, d') = |(d' - \theta)/\sigma|\). In the heteroscedastic case \(D'_{\theta} = \theta + N_{\theta}\), \(N_{\theta} \sim \mathcal{N}(0, \sigma^2(\theta))\), one uses \(T(\theta, d') = |(d' - \theta)/\sigma(\theta)|\) instead.

Coverage under the true sampling law

The coverage statement now follows directly from the observation kernel. Before observation, if the true datum is \(\dtrue\), then \(\Dobsrand \sim \L(\dtrue, \cdot)\). The random confidence set is \(\Calpha(\Dobsrand) = \{\mathbf d : \Dobsrand \in A_{\alpha}(\mathbf d)\}\).

The event \(\dtrue \in \Calpha(\Dobsrand)\) is equivalent to \(\Dobsrand \in A_{\alpha}(\dtrue)\). Therefore: \[ \begin{aligned} \Prob_{\dtrue}\!\left( \dtrue \in \Calpha(\Dobsrand) \right) &= \Prob_{\dtrue}\!\left( \Dobsrand \in A_{\alpha}(\dtrue) \right) \\ &= \L\!\left( \dtrue, A_{\alpha}(\dtrue) \right) = 1 - \alpha. \end{aligned} \]

The confidence set contains the true datum exactly when the random observation falls inside the true datum's own acceptance region. Since that region was chosen to have probability \(1-\alpha\) under the true sampling law, coverage follows. The additive shifted-noise proof was only one special version of this argument.

Decision rules with worst-case guarantees

In high-stakes problems, one often needs a decision rather than only a confidence set. Let \(\mathcal{H}_{\mathrm{danger}} \subseteq \Dspace\) denote the set of true data values corresponding to a dangerous state. A decision rule \(\delta : \Dspace \to \{0, 1, \mathrm{inc}\}\) maps the observation to a verdict: absent, present, or inconclusive.

If the dangerous error is a false negative, the event of concern is \(\delta(\Dobsrand) = 0\) when the truth actually belongs to \(\mathcal{H}_{\mathrm{danger}}\). A frequentist safety guarantee takes the form \[ \sup_{\mathbf d \in \mathcal{H}_{\mathrm{danger}}} \Prob_{\mathbf d}\!\left( \delta(\Dobsrand) = 0 \right) \leq \alpha. \] This means: no matter which dangerous true datum is the actual truth, the probability of falsely declaring absence is at most \(\alpha\). The supremum gives a uniform guarantee over all dangerous truths — no prior over \(\mathcal{H}_{\mathrm{danger}}\) is required.

A natural conservative rule can be built from confidence sets: declare the dangerous feature absent only when \(\Calpha(\dobs) \cap \mathcal{H}_{\mathrm{danger}} = \varnothing\). If any dangerous truth remains compatible with the observation, the responsible decision is not to clear the dangerous state.

Why it works

If \(\dtrue \in \mathcal{H}_{\mathrm{danger}}\) and the rule falsely declares absence, then \(\dtrue \notin \Calpha(\Dobsrand)\). So the false-negative event is contained in the coverage-failure event: \[ \{\delta(\Dobsrand) = 0\} \subseteq \{\dtrue \notin \Calpha(\Dobsrand)\}. \] Taking probabilities: \(\Prob_{\dtrue}(\delta(\Dobsrand) = 0) \leq \Prob_{\dtrue}(\dtrue \notin \Calpha(\Dobsrand)) \leq \alpha\).

This is the general frequentist answer in safety-critical settings. Whether the observation law is additive, heteroscedastic, multiplicative, or nonlinear, the frequentist can work directly with the observation kernel and design rules with uniform error guarantees.

The price of conservatism

If the likelihoods for dangerous and non-dangerous truths overlap substantially, then many observations will remain inconclusive. That is not a defect of the construction. It is the sampling model saying that the data are not strong enough to safely support a sharper verdict.
