Bayes, Measure-Theoretically

A tiny inverse problem, solved twice — first by tables, then by kernels.

What to expect

This short example presents a simple discrete inverse problem that we will solve using Bayesian inversion. The purpose is to introduce key concepts of measure theory and develop quickly (and informally) the measure theoretic form of the Bayesian formula. I did not write this for people that have never seen Bayesian inversion, but rather for those that dipped their toes in bayesian waters, but are still afraid of the measure theoretical sharks lurking in the deep waters.

The example is deliberately small. There are only four possible hidden states and only two possible reports. This means that, in principle, we can solve the whole problem by drawing a table and doing ordinary probability arithmetic. That is not a weakness of the example. It is the point.

We will solve the same problem twice. (The classics behind each pass are linked throughout and collected below: Bayes’s essay for the table-and-normalize reasoning, Kolmogorov for the axioms, Chang and Pollard for conditioning as disintegration, Stuart for where the machinery finally pays off.)

First, in Part 2, we solve it in the most elementary way possible. We list all possible hidden switch configurations, all possible reports, and all joint probabilities. Then we condition on each possible report by selecting the appropriate part of the table and normalizing. No measure theory is needed. The only operations are multiplication, addition, and division.

Second, in Part 3, we solve the same problem again using the language of measure theory. The prior becomes a probability measure on the model space. The reporting mechanism becomes an observation kernel. The combined experiment becomes a joint measure. The Bayesian update becomes a posterior kernel.

The important point is that the observed report is not used to build the theory. The theory is built before the report arrives.

In other words, our goal is not merely to compute \[\mathbb{P}(m \mid \dobs)\] for one particular observed value \(\dobs\). Our goal is to construct the whole update rule \[d \longmapsto \mathbb{P}(m \mid d).\] Only after this rule has been constructed do we plug in the actual observation \(\dobs\).

This distinction is small in the finite example, but it becomes essential later. The finite table we build in Part 2 is the baby version of the posterior kernel constructed in Part 3.

The four parts

Part 1 — The Game. We set up a small guessing game with two hidden switches, a lightbulb, and an unreliable reporter. We specify the model space, the data space, the forward map, the noise model, and the prior.

Part 2 — The High-School Solution. We solve the game using only multiplication, addition, and division. We build the joint table, compute predictive probabilities, normalize each column, and obtain the full posterior update rule.

Part 3 — From Points to Events, Conditioning and Its Limits, Conditional Expectation, Disintegration, Bayesian Inversion, and Back to Finite Land. We re-express the same calculation in the language of measures, kernels, and sigma-algebras. The prior becomes a measure, the reporter becomes a kernel, the joint table becomes a joint measure, and the posterior becomes a kernel. We climb to measure theory and descend back to recover the finite answer.

Part 4 — Summary & Notation Map. We collect the two stories side by side, state the final slogan, and provide a dictionary between the elementary and measure-theoretic notations.
