# References protocol migration — Phase 1 complete

**Plan:** `docs/agent-docs/plans/completed/references-protocol-migration-plan.md`
**Completed:** 2026-07-24

## Result

Created `references/PROTOCOL.md` and `references/INDEX.md`. The protocol now
separates maintained living descriptions from source-evidence dossiers and
defines their authority, update triggers, privacy boundary, and retirement.

## Settled decision

The index selects the first relevant reference for a task. It is not automatic
context and it does not command an agent to load the whole reference library.
