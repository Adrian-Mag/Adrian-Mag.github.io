# Reference index

Use this compact registry to choose the first reference record relevant to a
task. It is not automatic context; an unrelated task need not open every row.

| Need | First record | Why |
| --- | --- | --- |
| Change a served page, stylesheet, navigation, or site script | `living/website-reference.md` | Current site structure, conventions, file map, and focused checks. |
| Understand or change the agent-document architecture | `living/agent-docs-reference.md` | Current protocol ownership, entry bridges, and privacy boundary. |
| Draft or verify a public Machine Around the Model claim or exhibit | `sources/machine-around-the-model-sources.md` | Verified dates, provenance, caveats, and explicit evidence gaps. |
| Verify or revise a citation or research claim with a local paper or prior audit record | `../citation-audit/PROTOCOL.md` | It routes private evidence to the local PDF-reading skill without publishing it. |
| Create, revise, follow, complete, or archive substantial work | `../plans/PROTOCOL.md` | Plan lifecycle rules are owned by the plans protocol. |
| Audit or change agent-work procedures, event vocabulary, reports, or host observation | `../agent-ledger/PROTOCOL.md` | The Agent Ledger owns soft observability rules; it does not replace plans or references. |
| Resolve a conflict with a reference | Current source, Git, and the relevant primary evidence | They outrank a maintained summary. |
